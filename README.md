# Презентация АО «РТ-Техприемка» — деплой

## Что внутри
- `index.html` — готовая презентация одним файлом (все шрифты, изображения и скрипты встроены, ~13 МБ). Работает офлайн, без сборки.

## Задача для Claude Code
Задеплоить `index.html` как статический сайт. Сборка не нужна — это финальный файл, его не нужно переписывать или переделывать во фреймворк.

Варианты:
- **Vercel:** `npx vercel deploy --prod` в этой папке.
- **Netlify:** `npx netlify deploy --prod --dir .`
- **GitHub Pages:** закоммитить `index.html` в корень репозитория → Settings → Pages → Deploy from branch.
- **Любой хостинг/Nginx:** положить `index.html` в корень веб-сервера.

Требования к хостингу: отдавать `index.html` с `Content-Type: text/html; charset=utf-8`. Ограничения на размер файла — не менее 15 МБ (у всех перечисленных сервисов ок).

## Управление презентацией
- ← / → или пробел — переключение слайдов
- Формат слайдов 1920×1080, масштабируется под окно
- Печать в PDF: Ctrl/Cmd+P (по слайду на страницу)
