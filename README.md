# Презентация АО «РТ-Техприемка» — деплой на GitHub Pages

## Что внутри
- `index.html` — готовая презентация одним файлом (~8 МБ). Шрифты, изображения и скрипты встроены, работает офлайн, сборка не нужна.

## Задача для Claude Code
Опубликовать `index.html` как статический сайт на GitHub Pages. Файл финальный — не переписывать, не переносить во фреймворк, не править вручную.

Шаги:
1. Создать репозиторий (например, `rt-techpriemka-deck`): `gh repo create rt-techpriemka-deck --public --source . --push` либо через веб-интерфейс.
2. Положить `index.html` (и этот README) в корень ветки `main`, закоммитить и запушить.
3. Включить Pages: `gh api -X POST repos/{owner}/rt-techpriemka-deck/pages -f "source[branch]=main" -f "source[path]=/"` или Settings → Pages → Deploy from branch → `main` / `(root)`.
4. Добавить пустой файл `.nojekyll` в корень (чтобы Pages отдавал файл как есть).
5. Через 1–2 минуты сайт доступен по адресу `https://{owner}.github.io/rt-techpriemka-deck/`.

Лимиты GitHub: файл ~8 МБ — в пределах (предупреждение начинается с 50 МБ).

Альтернативы: Vercel (`npx vercel deploy --prod`), Netlify (`npx netlify deploy --prod --dir .`).

## Управление презентацией
- ← / → или пробел — переключение слайдов
- Формат 1920×1080, масштабируется под окно
- Печать в PDF: Ctrl/Cmd+P (по слайду на страницу)
